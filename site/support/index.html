Support

Your Name for Threads is a one-person open-source project. Help is given as soon as possible, with no guaranteed response time. Only the latest stable Chrome and Edge are officially supported.

Something is not working

  1. Open the Dashboard (Open Directory in the extension's popup), go to About & Privacy and choose Copy diagnostics.
  2. Report an issue on GitHub, say what happened and paste the diagnostics into the optional diagnostics field.

Diagnostics are kept on this device, up to the 20 most recent events, and are never uploaded automatically. The copied diagnostics include the version, runtime state, counts and error codes.

Please do not paste private nicknames, notes, a full JSON backup or recovery data into a public issue. For a security vulnerability or a privacy leak, use the private channel described in the security policy.

A GitHub issue is public, and nothing is attached to it for you.

Questions and ideas

Questions and feature requests go to GitHub Issues, without any private data.

Security problems and privacy leaks

Do not open a public issue with the details. The security policy says what to report and how to report it privately.

If the extension says your data needs recovery

Choose Export recovery data first. Clearing the damaged data deletes it for good, and the recovery file is the only copy you can keep. It may hold private nicknames and notes, so keep it private. The privacy policy lists every choice you have.
